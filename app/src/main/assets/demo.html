Font Scale × WebView

OSの「設定 → ディスプレイ → フォントサイズ」でフォントサイズを変更すると、 アプリが onConfigurationChanged で検知してこのページに反映されます。

🔤 WebView の body フォントサイズ（実測値） ---
✅ 対応済み — em 単位で指定
GOOD
お知らせ：新機能がリリースされました

このテキストは em 単位 で指定しています。JavaScript で更新される body の font-size を起点に、 フォントスケールの変更に連動してスケールします。

GOOD
アクセシビリティ対応のコンテンツ

タイトル: font-size: 1.143em（≈16px）、説明文: font-size: 0.857em（≈12px）。 em により body のサイズ変化に追従します。

❌ 未対応 — px を固定指定
BAD
お知らせ：新機能がリリースされました

このテキストは px 固定（16px / 12px）です。上のセクションと比べてください。 フォントスケールを変更してもサイズが変わりません。

BAD
アクセシビリティに非対応のコンテンツ

文字サイズを大きく設定しているユーザー（約 25〜35%）にとって、 このテキストは読みにくいままです。

実装のポイント
// ① onConfigurationChanged でスケール変化を検知
override fun onConfigurationChanged(newConfig: Configuration) {
  super.onConfigurationChanged(newConfig)
  val scale = newConfig.fontScale
  webView.evaluateJavascript("setFontScale(${'$'}scale)", null)
}

/* ② font-size は em（body 基準の相対値）*/
.title {
  font-size: 1.143em; /* ✅ スケールする */
}

/* ❌ px 固定はスケールしない */
.bad-title {
  font-size: 16px; /* ❌ 変化しない */
}
