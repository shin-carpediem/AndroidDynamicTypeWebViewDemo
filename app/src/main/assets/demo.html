Font Scale × WebView

OSの「設定 → ディスプレイ → フォントサイズ」でフォントサイズを変更すると、 setTextZoom(int) 経由で WebView 全体のテキストが拡大縮小されます。 CSS の単位（px・em）に関係なくスケールされます。

✅ テキスト — px でも em でも setTextZoom でスケールされる
px 固定
お知らせ：新機能がリリースされました

font-size: 16px（固定値）— setTextZoom によりレンダリングエンジンレベルで OS の倍率がかかるため、px 固定でもスケールされます。

em 相対
アクセシビリティ対応のコンテンツ

font-size: 1em（相対値）— 同じく setTextZoom でスケールされます。 px と em の差は setTextZoom の前では現れません。

⚠️ 非テキスト要素 — setTextZoom の影響を受けない
🔔
アイコンのサイズは変わらない

丸枠は width/height: 48px のまま。 テキストが大きくなるとアイコンとのバランスが崩れます。

横幅 200px の固定バナー

width: 200px; height: 44px は変わらない。 テキストが大きくなると overflow でバナーからはみ出します。

実装のポイント
// ① onConfigurationChanged でスケール変化を検知
override fun onConfigurationChanged(newConfig: Configuration) {
  super.onConfigurationChanged(newConfig)
  applyFontScale(newConfig.fontScale)
}

// ② setTextZoom で WebView 全体のテキストをスケール
private fun applyFontScale(fontScale: Float) {
  // fontScale 1.0 → 100（標準）, 2.0 → 200（200%）
  webView.settings.textZoom = (fontScale * 100).roundToInt()
}

/* CSS 単位は問わない — px も em もスケールされる */
.title    { font-size: 16px; } /* ✅ スケールされる */
.subtitle { font-size: 1em;  } /* ✅ スケールされる */
